# 内容发布工作台｜社区版使用手册

社区版提供 **图文素材准备、内容分发计划、人工发布提醒与结果核对**。平台名称是账号分类标签，**不代表已经连接 Instagram、Facebook、X 或任何其他平台的官方 API**。

## 启动

电脑安装 Node.js 22/24 后执行 `npm ci && npm run dev`，在当前电脑浏览器打开终端提供的 `127.0.0.1` 地址。不要把本机地址当作可以被手机远程连接的服务。

## 1. 社媒账号管理

在「我的账号」登记账号备注、目标平台及设备，不需要平台密码。支持批量登记，每行四列：

```text
创作号|Instagram|windows|Win-A
品牌号|X|mac|Mac mini
产品号|Facebook|phone|iPhone-1
活动号|TikTok|phone|Android-1
运营号|小红书|mac|MacBook
备用号|其他平台|windows|Win-B
```

前三列的含义为：**账号备注 | 平台分类 | 设备类别**，最后一列为设备名称。旧版三列格式也可导入，平台默认「其他平台」。

这些名称只是示例，没有保证对应客户端一定支持某种自动操作。仅登记自己或明确获授权操作的账号。

## 2. 图文素材库

填写标题和正文，最多添加 9 张 PNG/JPEG/WebP 图片，单张不超过 4 MB。媒体文件存放在本机；创建新版本后，未完成的旧版本任务将需要重新分配。

## 3. 内容分发计划

选取已有内容和多个目标账号，创建逐账号任务。每个任务单独保存账号信息、内容版本、审核状态和可见范围提醒；可以为不同账号修改正文。

审核通过后才能获取该账号对应的素材包，避免把未审核文案错发。

## 4. 人工发布提醒与素材交接

点击「获取发布素材包」下载 ZIP，其中包含正文 TXT、发布说明与原图。把文件交接到该账号正在使用的手机或电脑，由操作者在目标平台的**官方客户端里自行发布**。

**发布提醒只是工作台待办，不会在后台计时推送，也不会自动发布内容。**

## 5. 发布结果核实

实际完成发布后，在工作台选择「标记已发布」，再亲自打开该账号的已发布内容列表，确认图文已出现，最后点「确认发布结果」。

如无法确认是否发出，则选择「结果不确定」，并先在目标平台核查。确认没有发布后才允许解除任务锁定，避免重复发帖。

## 数据和边界

数据默认存储在本机 `~/.kadadesk-community/`，不同电脑之间不会自动同步；图片 ZIP 由你手动传送。不要向公共仓库上传账号、客户消息或密码。免费自用、研究及商业授权范围详见 [LICENSE](../LICENSE)。
