# 快速使用｜6+ 个人微信号朋友圈运营

**这是一款本地内容协作工具：只管理素材与任务，不会自动登录或发表个人朋友圈。**

安装 Node.js 22/24，运行 `npm ci && npm run dev`，终端会给出本机地址。电脑上的浏览器打开；手机不能直接远程连 `127.0.0.1`。

### 一次性登记账号

「我的账号」→「批量登记」，每行一个：

```text
个人主号|windows|Win-A
业务号|mac|Mac mini
品牌号|phone|iPhone-1
客服号|windows|Win-B
社群号|phone|Android-1
课程号|mac|MacBook
```

仅输入备注，不需要微信密码或真实微信ID。只操作自己或已获得明确授权的账号。

### 内容只制作一次

「内容库」粘贴正文并添加配图，每张不超过4MB、最多9张。保存后在「发布任务」选中该内容，勾选多个账号。一条内容会生成多个**独立任务**。

每个任务可单独修改正文和可见范围提醒。修改后需重新审核，防止把旧图文发出去。

### 每个账号拿到自己的材料

审核通过后点「一键打包文案+配图」，获得包含 `朋友圈正文.txt`、`发布说明.txt`、编号图片的 ZIP 文件。通过你自己的 AirDrop/文件传输方法送到其他设备。**此操作不等于已经发布**。

在目标设备的原生微信里，人工核对当前登录账号、正文、图片和可见范围，亲自点击发表。返回咔哒点击「我在原生微信已发布」，再查看该账号本人朋友圈中实际存在对应内容，最后点击「核实发布成功」。

如果不确定是否发布：标记「结果不确定」，手工确认没有发出后才允许解除锁定。不要盲目重复发。

### 隐私与限制

- 数据默认写入当前电脑的 `~/.kadadesk-community/`，不会自动同步到其他手机或电脑。
