# 基础知识库插件｜本地人工审核与检索

在咔哒工作台打开「插件管理」，确保「基础知识库」处于启用状态，然后打开「知识库」。

## 当前功能

- **录入**：输入标题、正文和标签，生成「待审核」草稿；只有自己决定审核通过后才能检索到。
- **审核**：点击「人工审核通过」，自动将该条设为已审核且启用。
- **检索**：输入问题，获得已审核且当前启用的本地知识匹配结果；没有从第三方抓取信息，也不会自动对客户发送回复。
- **管理**：停用某条知识使它不再出现在检索结果中；重新启用时需要已经过审核；删除需要人工确认。
- **本地存储**：资料保存在本机 `~/.kadadesk-community/knowledge-community-v1.json`；关闭或重开服务不会清除数据。

## 真实限制

目前仅支持**本地文本录入**，不是完整企业文档导入/向量 RAG；没有调用大模型 API，没有云端同步和团队权限。工作台当前为单机单工作区，请勿将其直接暴露到公网作为多人平台。

本插件和内容运营模块分别启停。关闭知识模块只阻止 API 和工作台操作，**不会删除知识**；原始私有产品里更完整的知识/回复能力正在做依赖与版权审查，不代表全部已经迁入公共版本。

## 贡献建议

欢迎补充本地 Markdown/TXT 文档导入、删除确认与版本控制、分段检索评测、可追溯的资料来源、单元测试、模块 SDK。任何企业数据、真实客户个人信息或厂商私有连接器都不能作为测试样例提交。
