# 暂停与急停

咔哒随时可以叫停。暂停是「先歇一会儿」，急停是「马上停下所有动作」。

## 暂停和继续

暂停后，咔哒不再自动回复。正在发的这条会发完再停，不会发一半。

三种办法：

- 快捷键：Mac 是 ⌃⌥K（Control + Option + K），Windows 是 Ctrl+Alt+K。按一次暂停，再按一次继续
- 小浮窗：点「暂停接待」，要继续时点「继续接待」
- 接待页：在「接待 → 运行」点「暂停」

## 急停 {#emergency}

咔哒操作不对、或你想马上用电脑时，按急停。所有动作立刻停下，键盘鼠标马上还给你。

三种办法：

- 快捷键：Mac 是 ⌃⌥Esc（Control + Option + Esc），Windows 是 Ctrl+Alt+Esc
- 小浮窗：点「急停」
- 接待页：点「紧急停止全部任务」

菜单栏（Windows 是右下角任务栏）的咔哒图标里也有「停止全部任务」。

急停以后要重新开始，到「接待」点「开始接待」。

## 停止

在「接待 → 运行」点「停止」，本次接待就结束了。要再接待，点「开始接待」。

## 快捷键在哪改

到「设置 → 快捷键」。点「修改」，按下新的组合键。

快捷键在任何软件里都能用，按下去不会往聊天框里打字。

要按住 Ctrl、Alt（Mac 是 ⌃、⌥ 或 ⌘）里至少一个，再按一个键。改不好就点「恢复默认」。

提示「这组键被占用了」，说明别的软件也在用，换一组就行。

## 退出咔哒

点菜单栏（Windows 是右下角任务栏）的咔哒图标，选「退出咔哒」。

退出后客户的消息不会再自动回复。
