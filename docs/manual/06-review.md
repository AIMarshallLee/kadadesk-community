# 审核模式

审核模式就是「发送前先给你看」。你点了「发送」才发出去。

## 在哪里设

到「接待 → 接待设置 → 发送前审核」，在「审核模式」里选：

- 不审核，直接回
- 只审核退款 / 投诉 / 议价
- 审核新客户和退款 / 投诉 / 议价
- 每条都先给我看（刚开始用推荐）

改完点页面下面的「保存设置」。正在接待时会显示「暂停并保存」：正在发的这条发完后暂停、保存，再按新设置继续接待。

## 审核的回复在哪里看

写好的回复会出现在两个地方：

- 小浮窗上的「等你确认的回复」
- 「接待 → 运行」页的「待审核的回复」

每条都能看到是谁、客户说了什么、咔哒想怎么回。

## 三个按钮

- 发送：照这样发出去
- 改一下：改好再发。勾上「存进知识库，以后同样的问题就这样回」，下次咔哒就照你改的回
- 跳过：这位客户留给你自己回

## 没来得及处理

两小时没处理，这位客户就转给你，出现在「待处理客户」里。

现在没在接待时点「发送」，会先记下，开始接待后发出。

## 在手机上审核

填了「管理员联系人」，审核的回复也会发到那个聊天账号。

要在手机上批准，先给管理员的备注名「加上暗号」，再设好手机验证器。没加暗号时，手机上只能回「2 #编号」跳过，要到电脑上发送。

## 只给某些人审核

在「联系人设置」里，可以把某个人、某个标签设成「我确认再发」。其他人照常自动回复。详细看 [按人设置](#manual/contacts)。
