# 知识库

知识库是咔哒生成业务问答与回复草稿的核心依据。产品介绍、价格表、常见问题、售后规则等均保存在这里。

## 知识页结构

点击左侧导航栏的「知识」，包含以下主要功能模块：

- 导入与试答：拖拽导入资料、自动更新的知识来源、试答演练、待补充知识、本地资料库。
- 管理资料：按条目查看、审核、启用、停用、编辑与删除。
- 查找测试：批量测试检索效果，验证知识召回率与准确度。

## 导入资料 {#import}

最简单的方式：在「导入与试答」页面，将文件或文件夹拖拽至上传区，点击「开始整理」。具体步骤请参考 [怎么把资料丢进来](#manual/import)。

推荐在本地建立专门的资料文件夹：

1. 在「导入与试答」找到「本地资料库」，选择或指定本地文件夹目录。
2. 放入文件后，咔哒可在检测到文件变动时自动触发增量提取。
3. 当产品规则或价格发生变动时，直接替换原文件即可。

## 自动更新的知识来源 {#auto-sources}

资料若存放在 GitHub 仓库或特定本地目录下且经常变动，可以配置自动更新来源：

1. 点击「添加 GitHub 仓库」，填入仓库 URL（例如 `https://github.com/org/repo`），或点击「添加本地文件夹」。
2. 系统会自动解析目录结构并给出建议：如销售、话术、品牌、FAQ、产品文档等默认勾选；内部技术、架构、敏感规范等默认排除。
3. 为勾选的文件夹指定分类用途：
   - 业务问答用：提炼为问答对，用于对外草稿与试答；
   - 风格参考：学习表达风格与语气，不作为既定事实引用；
   - 内部参考：作为背景资料索引。
4. 点击「按这个选择开始导入」。

后续机制：

- 自动同步：后台定时检查变动，仅在系统空闲时执行增量解析；
- 手动同步：随时点击「立即更新」进行即时拉取；
- 冲突保护：增量更新仅覆盖变动文件，手工在「管理资料」中深度编辑过的条目不会被暴力覆盖；
- 安全过滤：自动检测并剥离代码与文本中的 API Key、私钥等机密信息。

## 整理与审核 {#review}

在知识页面顶部可配置审核策略：

- 启用直接使用：整理好的条目自动生效，适用于公开标准化材料。
- 人工复核：新提炼出的条目先进入待复核状态，店主核对无误后勾选启用。

存在争议冲突、包含占位符未填或提示内部机密的内容，系统均会强制要求人工确认。

## 冲突处理 {#conflict}

当新导入的资料与现有知识库表述矛盾时，咔哒不会盲目覆盖，而是标记为待确认冲突：

在整理结果中可直观比对新旧条目，选择「停用旧条目并启用新条目」，或保留旧条目并调整新条目。

## 试答演练与持续完善 {#learning}

在「导入与试答」下方的「试问一句」输入框输入客户高频问题，点击「试答」：

- 系统将展示召回的参考资料以及大模型生成的回复草稿；
- 若回复不满意，可直接点击跳转编辑该条知识或补齐缺失的解答；
- 未能命中有效知识的问题会自动记录在「待补充知识」清单中，方便集中补充。

## 跨设备迁移与备份

- 导出与共享：在「管理资料」中点击「导出知识包」，可将知识库打包为便携格式，在另一台设备上直接导入。
- 自动备份：在「导入与试答」页面可设置本地或同步盘备份路径，支持每日定时快照。
