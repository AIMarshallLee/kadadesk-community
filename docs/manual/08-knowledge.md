# 知识库

知识库就是咔哒回答客户时看的资料。产品介绍、价格表、常见问题、售后规则，都放这里。

## 知识页有什么

点左边的「知识」。上面一排标签：

- 导入与试答：拖资料进来、自动更新的知识来源、试问一句、待补充知识、本地资料库
- 管理资料：一条条看、审核、启用、停用、编辑、删除
- 我的资料源：资料放在电脑文件夹里时，直接选那个文件夹
- 连接网盘、连接在线知识库（飞书 / Notion）：点「更多方式 ▾」能看到
- 查找测试：一次测很多问题，看咔哒能不能找到对的资料

## 导入 {#import}

最简单的办法：在「导入与试答」把所有资料一股脑拖进来，点「开始整理」。步骤看 [第二步 导资料](#manual/import)。

资料多的话，建议建一个「咔哒资料库」文件夹：

1. 在「导入与试答」往下找「本地资料库」，点「就建在这里」或「换个位置」
2. 以后把文件放进「01 原始资料」，咔哒每 2 分钟自动整理
3. 价格变了，直接用新文件替换旧文件

资料库里有几个子文件夹：01 原始资料、02 新整理、03 在用的知识库、04 旧版本，还有一个放常用图片的文件夹。

## 自动更新的知识来源 {#auto-sources}

资料放在 GitHub 仓库或电脑上的某个文件夹里，而且会不定期更新：添加一次，以后咔哒自己更新。

在「导入与试答」往下找「自动更新的知识来源」：

1. 点「添加 GitHub 仓库」，贴上仓库地址（比如 https://github.com/用户名/仓库名），点「添加」。资料在电脑上的文件夹里（包括已经下载到电脑上的仓库），点「添加本地文件夹」
2. 咔哒列出里面的文件夹和每个文件夹有几份资料，并按名字先选好：销售、获客、话术、品牌、案例、常见问题、产品介绍、价格这类先选上；架构、技术、复盘、决策、索引、规范这类看着像内部资料的不选
3. 给每个选上的文件夹选用途：
   - 回复客户用：整理成客户问答，用来回答客户
   - 写法参考：只学写法和语气（比如爆款文案、自媒体内容），不当成事实告诉客户
   - 内部参考：存成内部资料，不用来回复客户
4. 点「按这个选择开始导入」。资料多的话第一次要一会儿，进度条上写着「已整理 N / 共 M 份」，随时可以点「停下」

以后：

- 自动更新：咔哒每 6 小时检查一次有没有更新，只在它不忙的时候（没有客户在等、没在写或发回复、电脑不卡、没按急停）。没变化就什么都不做
- 手动更新：点「立即更新」
- 只整理新增和改过的文件。改过的文件，它原来的知识会换成新的，不会重复
- 你在「管理资料」里改过的知识不会被覆盖。原文件更新出的新版本会等你决定用哪个
- 原文件删掉了，它的知识会停用（不删除），卡片上会写
- 一次最多整理 100 份要整理的文件，剩下的下次接着来。用免费试用模型时不整理大批资料，先按原文导入，接上自己的模型后会自动整理
- 资料里像密钥、密码的内容会自动隐藏。图片、程序文件、太大的文件会跳过
- 有更新时会弹一个提醒，比如「知识库更新了：新增 12 份、更新 3 份、停用 1 份」。读不了（没登录、没网）时卡片上会写原因，提醒一天最多一次

私有仓库用这台电脑已经登录的 GitHub 账号读取，咔哒不会问你要密码或令牌。读不了时，按卡片上写的做：装好 GitHub Desktop 并登录后把仓库下载到电脑上，再「添加本地文件夹」；或者在 GitHub 页面点「Code」→「Download ZIP」，下载后拖进来。

不想自动更新，把卡片上的「自动更新」勾掉。「移除」只是不再更新，导入的知识会留着。

## 整理和审核 {#review}

「知识」页最上面的开关：「咔哒整理好的知识直接用来回复客户（推荐）」。

- 开着：整理好的知识直接启用
- 关掉：新整理的知识要你点确认才会用

这些一定要你确认：行业样板、话术包、手动添加的、改过的知识、同一问题答案不同的、【】没填的、内部资料。

只有已审核、已启用的知识才会用来回客户。改过的知识会先停用，要再审核一次。

在「管理资料」里可以「批量审核」，一次最多 300 条。

## 冲突：同一个问题答案不一样 {#conflict}

新资料和已经在用的说法不一样时，咔哒不会自己选。它会把新的那条放着，等你决定。

在整理结果或「管理资料」里，你会看到「停用旧条目并启用新条目」。确认新的说法对，就点它。旧的那条会停用。建了资料库的话，它会放进「04 旧版本」，随时可查。

国内和海外价格不一样：分开导入，在资料里选「仅国内客户」或「仅海外客户」。不要把两套报价放在同一条里。

## 自主学习 {#learning}

咔哒会越用越懂你的生意：

- 咔哒答不上来，你亲自回了客户。咔哒会把你的回答记进知识库，下次自己答。闲聊、「好的」「稍等」、某个客户自己的订单问题不会记
- 审核时点「改一下」，勾上「存进知识库」，改过的回答也会存进去
- 和已有说法矛盾的，会等你确认

在「管理资料」里还有「进阶：从已审核的回复中持续学习」，可以把你确认过的问答提炼成知识，审核后才启用。

## 待补充知识

客户问过、咔哒没答上来的问题，会出现在「待补充知识」里。填一句答案就存成知识。

「数据」页的「知识库还缺什么」，也会列出转给你最多的问题。

## 不限条数，用多少都行 {#how-many}

知识不限条数。

到「接待 → 模型与回复 → 回复时参考哪些资料」：

- 全部已审核、已启用的资料（推荐）：每条消息咔哒自动挑跟问题有关的几条来回答
- 只用我勾选的资料：建议不超过 200 条。勾得更多也能用，只是挑资料会慢一点

内部资料、写法参考和没审核的资料不会用来回客户。

## 试答

在「导入与试答」写一句客户真会问的话，点「试答」。对照资料看答得对不对。

试答不会给客户发消息。

## 多台电脑共用一套知识

在「管理资料」点「导出知识包」，另一台电脑点「导入知识包」。

## 备份

在「导入与试答」往下找「备份」。选一个网盘的同步文件夹或 U 盘，咔哒每天自动备份一次，保留最近 14 天。一周多没备份会提醒你。
