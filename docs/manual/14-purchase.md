# 购买与激活

咔哒可以先试用。试用次数用完后，买一个授权就能一直用。

## 看还剩多少次

看顶部的皇冠按钮：

- 「软件试用余 N 次」：还在试用，还能用 N 次
- 「授权还剩 N 天」：已经买了，还剩 N 天
- 「商业版」：已经买了
- 「授权已到期」：要续费了

到期前 7 天会提醒你续费。

## 试用次数用完会怎样

接待不会停。新消息会标记「转人工」并提醒你，不丢客户。激活后自动恢复。

## 购买三步

点顶部的皇冠按钮，打开「购买与激活」。

1. 第 1 步：选套餐。有月度专业版和年度旗舰版，也要选销售地区
2. 第 2 步：付款。在线付款成功会自动激活，不用再填授权码
3. 第 3 步：填写授权码激活。把收到的授权码粘贴进去，点「激活」

## 人工付款

在线付款没开通时，第 2 步会显示收款码：

1. 用手机扫码付款
2. 点「复制付款信息」，发给客服 kadadesk_support。里面已经带上套餐和本机机器码
3. 客服核对后会回你一串以 FD1_ 开头的授权码（也叫卡密）
4. 在第 3 步粘贴，点「激活」

## 机器码是什么

机器码是这台电脑的编号。授权码按它生成，只能在这台电脑上用。

在「购买与激活」里点「一键复制机器码」，或到「设置 → 软件授权（卡密）」查看。

重启、重装咔哒，机器码都不会变，不用重新激活。

## 授权码不对

提示授权码无效或已过期：

- 确认整串都复制了，以 FD1_ 开头，不要带空格
- 确认是按这台电脑的机器码生成的

## 换电脑

授权码只能在原来那台电脑上用。新电脑的机器码不同，把新机器码发给客服处理。

## 授权管什么

授权只管软件本身，不含模型费用（内置模型版除外）。
