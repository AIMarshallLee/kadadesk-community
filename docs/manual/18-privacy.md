# 隐私与安全

咔哒社区版遵循「本地优先、用户掌控、隐私至上」的设计原则。

## 数据完全本地存储

- 你的业务知识库、客户档案、跟进记录及系统设置，均保存在当前电脑的本地 SQLite 数据库及本地文件中。
- 咔哒社区版没有私有中心服务器，不收集、不上报、不存储任何用户的业务数据。

## 调用大模型时的数据边界

当你在进行知识整理、问答试答或起草客户跟进建议时，咔哒仅会将最小必要的数据发送给**你所配置的模型服务商**（或发送给本地运行的私有模型如 Ollama）：

- 当前试答或跟进的问题上下文；
- 本地检索召回的相关知识片段；
- 系统提示词与预设语气风格。

不会发送未授权的本地文件、其他无关档案或非相关知识。

## 本地敏感信息护栏（Secret Guard）

咔哒内置了严格的敏感信息检测与拦截机制：

- 无论是导入知识文档、生成试答草稿，还是通过 MCP 服务提供知识检索，系统都会自动识别 API Key、密码、Token、手机号、身份证号、银行卡号等高危特征。
- 识别到敏感数据时，系统将自动进行掩码脱敏或弹出拦截警告，防止机密信息意外泄露。

## 本地密钥加密

配置的模型 API Key 均采用本地安全加密存储，界面上不显示明文。导出的备份数据与配置文件中绝不包含明文密钥。

## 本地诊断与求助日志脱敏

点击工作台顶部的「帮助与日志」生成的求助诊断包，仅包含应用版本、操作系统类型、脱敏的错误调用堆栈及性能耗时数据。

诊断包绝不包含知识库正文、客户信息或 API 密钥，且仅保存在本地设备中，完全由用户自主查看与决定是否提供给社区排查。
