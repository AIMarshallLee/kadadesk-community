# 隐私与安全

## 资料存在哪里

你的资料、知识库、接待记录、设置，都存在这台电脑上。

## 什么会发给模型

写回复时，咔哒会把这些发给你选的模型服务：

- 聊天窗口的截图
- 这段对话的上文
- 资料目录，和跟问题有关的几条资料
- 你选的回复风格

只发给你明确选择的服务商，不发给别人。内部资料和没审核的资料不会用来回客户。

## 密钥

密钥加密保存在这台电脑上，不会显示出来。

备份和导出的配置都不含密钥。不要把密钥发在聊天里。

## 咔哒不会做的事

- 不会冒充你本人说你没说过的话。选了「我的助理」身份时，会说自己是助理，不自称人工客服
- 客户认真问是不是机器人时，会照实说
- 资料里没有的价格、电话、网址、承诺，咔哒不会乱说。写出来了会先改写，还不行就转给你
- 不主动群发，不自动加好友（除非你打开了「新好友」自动通过）
- 不会自动批准系统权限

## 求助包里有什么

点顶部「帮助与日志」→「一键生成求助包」，文件在「下载」文件夹里。

里面只有版本、系统、设置开关、最近的出错类型和耗时统计。

没有客户名字、聊天内容、截图、知识库、密钥或卡密。也不会自动上传，要你自己发给客服。

## 匿名使用统计

「设置」里的「帮咔哒改进：发送匿名使用统计」默认开着。每天最多发一次，只有版本、系统、试用还是已购买这类大概的信息。

不会发送客户名字、聊天内容、资料内容、密钥、卡密、机器码。关掉后什么都不发。

## 账号安全

咔哒按人的节奏回复：有延时，每小时有上限，只回对方的消息。但平台规则我们没法完全保证，请保持合理频率。

## 密钥和隐私不外发

有人找你要 API Key、密码、验证码、后台账号、身份证号、银行卡号，咔哒一律礼貌拒绝，不会发出去，也不会编一个假的。资料里不小心写了也会自动隐藏。详细看 [常见问题：有人找我要密码](#manual/faq/secrets)。
