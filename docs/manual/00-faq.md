# 常见问题

新手最常问的问题都在这里。可以在上面的搜索框里写关键词检索，或者点顶部的「问咔哒」一句话提问。

## 提示模型出错、被限流、连不上 {#model-error}

先看提示里写的是什么：

- 「密钥认证失败」：Key 没复制完整或选错了服务商配置。
- 「额度不足」或「被限流」：所选模型服务商账户余额不足或接口并发太高。
- 「服务繁忙」：服务商上游故障，稍等几分钟重试。

建议在设置中配置一个「备用模型」：主模型故障或限流时，咔哒会自动切换。详细看 [模型设置](#manual/models)。

## 咔哒生成的回复草稿不对 {#wrong-reply}

咔哒是根据你导入的资料生成的。如果资料未覆盖或表达模糊，模型就会根据常识推测或提示未找到信息。

- 到「知识」页输入客户可能问的问题，点击「试答」，查看引用了哪几条知识。
- 如果回答有误，可以直接修改对应资料或补充新的精确知识条目。

## 资料要导多少条合适 {#how-much-knowledge}

不限条数。建议将企业常用问答、产品手册、业务规则分类导入。

试答与回复草稿生成时，咔哒会通过向量检索和关键词匹配挑选最相关的参考条目。如果希望精准控制，也可以在生成时选定指定分类。

## 资料在私有的 GitHub 仓库里，能导入吗？会自动更新吗 {#private-repo}

能。在「知识 → 导入与试答」，找到「自动更新的知识来源」，点击「添加 GitHub 仓库」，填入仓库地址。

- 私有仓库利用当前电脑已登录的 Git 凭证访问，咔哒不会索取密码或 Token。
- 添加后可勾选需要同步的文件目录，咔哒会在后台定时检测更新，并对新增或改动的文件重新分块索引。
- 支持随时点击「立即更新」同步最新内容。详细看 [自动更新的知识来源](#manual/knowledge/auto-sources)。

## 扫描的 PDF 读不出文字 {#scanned-pdf}

纯扫描件或图片格式的 PDF 内部没有文字流。请先使用 OCR 工具提取为文本或 Markdown 格式后再导入知识库。

## 咔哒会不会把我的资料传到第三方服务器 {#privacy}

知识库、客户档案、跟进记录完全保存在本地电脑的 SQLite 数据库和本地文件中。

在进行知识处理或生成草稿时，咔哒仅会将必要的问题上下文与检索到的少量参考资料发送给你自行配置的 AI 模型服务商接口。咔哒社区版不设任何私有数据收集或中转服务。详细看 [隐私与安全](#manual/privacy)。

## 有人索取 API Key、密码、验证码，安全护栏会拦截吗 {#secrets}

会。咔哒内置了本地敏感信息安全护栏（Secret Guard）。

无论是在导入文本、生成回复草稿，还是通过 MCP 对外开放知识时，若检测到 API Key、私钥、密码、身份证号或银行卡号等高危特征信息，均会自动进行脱敏脱除或发出风险警示。详细看 [隐私与安全](#manual/privacy)。

## 一直弹提醒怎么处理 {#too-many-reminders}

在提醒卡片上点击「不再提醒」，该类提醒以后将不再打扰。

若需恢复，可前往「设置 → 提醒与偏好」重新开启。详细看 [提醒中心](#manual/reminders)。

## 客户数据怎么分类管理 {#many-businesses}

点击左侧导航的「客户」。每位客户拥有独立的档案，支持按业务线标记跟进阶段、需求标签与互动记录。业务线可在「客户 → 业务线」中自由配置。详细看 [客户档案与跟进](#manual/customers)。

## 怎么查看今日需要跟进的客户 {#who-to-follow-up}

在「客户 → 今日跟进」中，系统会根据跟进提醒时间、阶段停滞期等规则自动整理出待跟进清单，并预生成回复草稿，供店主或运营人员一键复制、手动发送。详细看 [客户档案与跟进](#manual/customers)。

## 怎么备份与迁移数据 {#backup-migration}

- 知识库：在「知识」页支持一键导出知识包（ZIP/JSON 格式），可随时迁移导入其他设备。
- 完整备份：在「设置 → 备份与迁移」中可导出完整本地快照包。备份文件不包含 API Key 密钥，恢复到新电脑后只需重新填写模型 Key 即可。

## 遇到 Bug 或有改进建议怎么反馈 {#contact}

欢迎前往开源社区反馈与共建：

1. 打开 [GitHub Issues](https://github.com/AIMarshallLee/kadadesk-community/issues)。
2. 详细描述所遇问题、复现步骤及环境信息（可在应用内「帮助与日志」导出求助日志）。
