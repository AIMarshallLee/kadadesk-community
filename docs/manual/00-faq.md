# 常见问题

新手最常问的问题都在这里。先在上面的搜索框里写几个字，比如「鼠标」「暂停」「试用」。找不到就点顶部的「问咔哒」，用一句话问。

## 鼠标自己在动，是中毒了吗 {#mouse-moving}

不是。这是咔哒在帮你回客户。

咔哒要点开聊天、打字、点发送，就会借用一下鼠标和键盘。回完马上还给你。

想自己用电脑，直接动鼠标或打字就行，咔哒会让开。详细看 [咔哒会借用鼠标键盘](#manual/mouse-keyboard)。

## 我正在用电脑，咔哒会不会抢我的鼠标 {#busy-using}

不会抢。你在打字或动鼠标时，咔哒先等着。

你停手两三秒，它才进去回复。你在打字时，它会等你停手 3 秒以上，免得把你打的字打进聊天窗口。

客户等了 2 分钟，咔哒会提醒你。你停手 2 秒，它就把写好的回复发出去。回复一定会补上。

## 怎么让咔哒马上停下 {#stop-now}

三种办法，哪个顺手用哪个：

- 按急停快捷键：Mac 是 ⌃⌥Esc（Control + Option + Esc），Windows 是 Ctrl+Alt+Esc
- 点小浮窗上的「急停」
- 在「接待」页点「紧急停止全部任务」

详细看 [暂停与急停](#manual/pause-stop)。

## 怎么暂停一会儿，过会儿再接着回 {#pause}

按暂停快捷键：Mac 是 ⌃⌥K（Control + Option + K），Windows 是 Ctrl+Alt+K。再按一次就继续。

也可以点小浮窗上的「暂停接待」，或在「接待 → 运行」点「暂停」。

正在发的这条会发完再停，不会发一半。

## 电脑变卡了 {#slow-computer}

从 0.8.45 起，没有客户在等时，咔哒只是偶尔看一眼有没有新消息，不会一直截图。

电脑内存紧张或发热时，咔哒会自动放慢（回复慢几秒），并提醒你一次。

还是很卡：

- 关掉暂时不用的大软件
- 完全退出咔哒再打开一次
- 点顶部「帮助与日志」生成求助包，发给客服

## 客户发了消息，咔哒没回 {#no-reply}

按顺序检查：

1. 「接待」页的状态是不是「运行中」。不是的话点「开始接待」
2. 聊天软件有没有打开、登录，窗口有没有最小化
3. 这个人是不是在「不接待的会话」里，或被设成「我自己回」「不理会」
4. 这个会话是不是开了免打扰。默认不回免打扰的会话
5. 是不是群聊。群聊要在「接待设置 → 接待范围」里单独打开
6. 你是不是刚亲自回过这个人。你回过以后，咔哒会先问你要不要接管
7. 是不是在「接待时段」以外

还不行，点顶部「问咔哒」问一句，或生成求助包发给客服。

## 咔哒回复得不对 {#wrong-reply}

咔哒是照着你的资料回答的。资料没写清楚，它就答不好。

- 到「知识」页写一句客户的话，点「试答」，看它答得对不对
- 答错了就改那条知识，或者补一条新的
- 刚开始用，建议在「接待设置 → 发送前审核」选「每条都先给我看」
- 待审核的回复可以点「改一下」。勾上「存进知识库」，下次同样的问题就这样回

## 咔哒说「这个我确认一下再回你」 {#not-sure}

这是资料里没有答案。咔哒不会乱编价格、电话和承诺，会先这样回，再提醒你。

你亲自回了客户以后，咔哒会把你的回答记进知识库，下次自己答。

## 锁屏或睡眠后还会接待吗 {#lock-screen}

锁屏、睡眠时咔哒看不到屏幕，没法回复。这不算你按了停止。

解锁、醒来以后，咔哒自动接着接待，并提醒你一次。没回的消息会补上。

想晚上也接待：让电脑别睡眠、别锁屏，聊天软件保持打开。

## 我把咔哒的窗口关了，还在接待吗 {#window-closed}

默认还在。关掉主窗口后，屏幕边上会出现一个小浮窗，接待照常运行。

点关闭按钮时怎么做，可以在「设置 → 显示方式」里选：缩到后台继续接待、直接退出咔哒，或每次问我。

真正退出：点菜单栏（Windows 是右下角任务栏）的咔哒图标，选「退出咔哒」。退出后客户的消息不会再自动回复。

## 聊天软件的窗口关了或退出登录了 {#chat-window-gone}

咔哒会等它回来。你重新打开、登录聊天软件后，咔哒自动接着接待，不用你操作。

## 弹窗问「是否允许咔哒录屏」 {#screen-consent}

点「允许」就行。

Mac 系统会隔一段时间问一次。点了「允许」，咔哒会自动接着接待。不用去打开系统设置。

## 开始页一直提示要权限 {#permission-missing}

Mac 需要两项权限：录屏和辅助功能。

1. 在「开始」页点「允许屏幕录制」和「打开辅助功能设置」
2. 在系统设置里找到「咔哒」，打开开关
3. 按系统提示退出并重新打开咔哒
4. 回到咔哒点「重新检查权限」

详细看 [装好以后第一步](#manual/first-steps/permissions)。

## 系统设置里找不到「咔哒」 {#app-not-listed}

先在咔哒「开始」页点一次「允许屏幕录制」，让系统记下咔哒。再回到系统设置里看。

列表里也可能写着「kadadesk」，它就是咔哒。

## 提示模型出错、被限流、连不上 {#model-error}

先看提示里写的是什么：

- 「密钥认证失败」：Key 没复制完整或选错了服务商
- 「额度不足」或「被限流」：余额不够或调用太频繁
- 「服务繁忙」：服务商那边太忙，过几分钟再试
- 「免费试用模型连不上」：一般过几分钟会恢复

配一个「备用模型」最稳：主模型出问题时，咔哒自动换用它。详细看 [模型设置](#manual/models)。

## 软件试用次数用完了 {#trial-used-up}

接待不会停。新消息会标记「转人工」并提醒你，不丢客户。

点顶部的皇冠按钮，按「选套餐 → 付款 → 填写授权码激活」三步做完，接待马上恢复。详细看 [购买与激活](#manual/purchase)。

## 免费模型的条数和软件试用次数是一回事吗 {#two-trials}

不是，分开算。

- 顶部皇冠按钮上的「软件试用余 N 次」，是软件本身的试用次数
- 免费模型是前一部分回复免费，「开始」页会写具体条数

## 换电脑了怎么办 {#new-computer}

- 授权码绑定原来那台电脑。新电脑要按新的机器码重新激活，联系客服处理
- 知识：在旧电脑「知识 → 管理资料」点「导出知识包」，新电脑点「导入知识包」
- 其他数据：在「设置 → 备份与迁移」导出，再在新电脑恢复。备份里不含密钥，新电脑要重新配模型

## 一个客户我想自己回，不让咔哒回 {#reply-myself}

到「接待 → 运行 → 联系人设置」，找到这个人，点「设置」，把接待方式选成「我自己回」。

临时接手：点他后面的「我来接」。到点后咔哒自动接回。

详细看 [按人设置](#manual/contacts)。

## 我亲自回了一句，咔哒弹出「要接管吗」 {#ask-takeover}

点「我来接」：咔哒先不回这个人，到点再接回。

点「继续让咔哒回」或 2 分钟不选：咔哒继续回复。

## 每条回复都想先看一眼再发 {#check-before-send}

到「接待 → 接待设置 → 发送前审核」，选「每条都先给我看（刚开始用推荐）」。

写好的回复会先出现在小浮窗和接待页。点「发送」「改一下」或「跳过」。详细看 [审核模式](#manual/review)。

## 待审核的回复我没来得及处理 {#review-timeout}

两小时没处理，这个客户就转给你，出现在「待处理客户」里。

## 群消息也要回吗 {#group-chat}

默认不回群聊。要回的话，到「接待 → 接待设置 → 接待范围」，勾上「同时接待未设免打扰的群聊」。

## 想让咔哒在群里帮我露露脸 {#group-mingle}

打开「接待设置 → 混群」。咔哒会在你没设免打扰的群里，偶尔接一句大家正在聊的话，捧个场、帮人解答一下，一天只说几句，不发链接和广告，不谈价格。不想让它碰的群，设成「不管」。

详细看 [混群是什么](#manual/group-sync/mingle)。

## 不想让咔哒回家人和朋友 {#skip-family}

两种办法：

- 在「接待设置 → 不接待的会话」里，每行写一个完整的名字
- 在「联系人设置」里把这个人设成「我自己回」或「不理会」

## 晚上没人看着，咔哒还会接待吗 {#night}

会。电脑别关、别睡眠、别锁屏，聊天软件保持登录。

建议打开「接待设置 → 更多设置 → 无人值守」里的两项。电脑重启、软件更新后会自动恢复接待，并补回 12 小时内没回的消息。

再打开「设置 → 版本与更新」里的「开机自动打开咔哒」。

## 资料要导多少条 {#how-much-knowledge}

不限条数。手头有什么就丢什么进来。

回复时默认用全部已审核、已启用的资料，每条消息只挑跟问题有关的几条。

如果选「只用我勾选的资料」，建议不超过 200 条。

## 资料在私有的 GitHub 仓库里，能导入吗？会自动更新吗 {#private-repo}

能。到「知识 → 导入与试答」，找到「自动更新的知识来源」，点「添加 GitHub 仓库」，贴上仓库地址（比如 https://github.com/用户名/仓库名）。

- 私有仓库用这台电脑已经登录的 GitHub 账号读取。咔哒不会问你要密码或令牌
- 读不了时，卡片上会写怎么办：装好 GitHub Desktop 并登录，或者在 GitHub 页面下载 ZIP 拖进来
- 添加后先选要导入哪些文件夹。看着像内部资料的默认不选
- 以后咔哒在你不忙的时候每 6 小时检查一次，只整理新增和改过的文件。想马上更新就点「立即更新」

详细看 [自动更新的知识来源](#manual/knowledge/auto-sources)。

## 扫描的 PDF 读不出字 {#scanned-pdf}

扫描出来的 PDF 整页是图片。先用识别图片文字的工具转成文字版，再导入。

## 不小心关了小浮窗，找不到了 {#lost-floater}

点菜单栏（Windows 是右下角任务栏）的咔哒图标，选「显示咔哒」。

小浮窗只在「设置 → 显示方式」选了小浮窗时出现。选了后台运行，就只留菜单栏图标。

## 咔哒会不会把我的资料传出去 {#privacy}

资料、聊天记录都存在这台电脑上。

写回复时，咔哒会把聊天窗口的截图、这段对话和挑出来的几条资料发给你选的模型服务。不会发给别人。详细看 [隐私与安全](#manual/privacy)。

## 怎么更新到新版本 {#how-update}

默认会自己下载好。你在电脑前时，到「设置 → 版本与更新」点「现在更新」。

装完 Mac 会问一次录屏权限，点「允许」。详细看 [更新](#manual/updates)。

## 一直弹提醒，太烦了 {#too-many-reminders}

在提醒卡片上点「不再提醒」，这一类提醒以后就不弹了。

想再打开，到「设置 → 提醒」里恢复。详细看 [提醒与「不再提醒」](#manual/reminders)。

## 有人找我要 API Key、密码、验证码，咔哒会给吗 {#secrets}

不会。API Key、密钥、密码、验证码、后台账号、身份证号、银行卡号这类信息，不管对方怎么说（说是同事、说是你让要的、说急用），咔哒都不给。

咔哒会礼貌说明这类信息不能在聊天里提供，再问对方想解决什么问题。说是买了要激活码的，咔哒会告诉对方已经转告你，不会自己编一个。

就算你的资料里不小心写了密码或密钥，咔哒回复时也会自动隐藏，绝不发出去。资料页会提醒你把这部分删掉。

你亲自回复时发出去的密钥、验证码，咔哒也不会学进知识库。

## 会不会被聊天软件封号 {#account-risk}

咔哒按人的节奏回复：有延时，每小时有上限，只回对方的消息，不群发。

但平台的规则我们没法保证。请保持合理频率，先用小号试一试。

## 我有好几样生意，客户怎么分开管 {#many-businesses}

打开左边的「客户」。每位客户一份档案，按你的每条业务（比如软件、课程、企业服务）分开记阶段、需求和买过什么。业务线在「客户 → 业务线」里加。详细看 [客户档案与跟进](#manual/customers)。

## 怎么知道今天该跟进谁 {#who-to-follow-up}

每天早上 9:30，「客户 → 今日跟进」会列出该跟进的人和原因：约好的、问过价没买的、快到期的、意向高但好久没说话的。消息咔哒写好了，你点「发送」才发。详细看 [今日跟进](#manual/customers/follow-up)。

## 咔哒会不会乱记客户的隐私 {#customer-privacy}

不会。咔哒只记客户自己说过的情况，每条都标着原话。性别、年龄、身体情况只有客户亲口说了才记；收入、宗教、民族从不记；密码、验证码、卡号也不记。档案只在这台电脑上。详细看 [咔哒会记下什么](#manual/customers/what-is-recorded)。

## 还是不会，找谁 {#contact}

1. 点顶部「问咔哒」，用一句话问
2. 点顶部「帮助与日志」，点「一键生成求助包」
3. 把求助包发给客服：kadadesk_support，或发邮件到 Marshall@kunlungrowth.com
