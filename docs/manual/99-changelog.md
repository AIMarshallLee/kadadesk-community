# 更新记录

每个版本改了什么，最新的在最上面。看自己的版本：「设置 → 版本与更新」。

## 0.3.0

- 咔哒社区核心版开源发布：提供干净的工作台框架、知识库管理与试答、通用文字模型客户端、客户档案、安全护栏与 MCP 开放生态
- 架构解耦：移除专有渠道自动化与商业授权模块，回归企业私域 AI 核心能力

## 0.8.50

- 页面不再左右滚动：长链接、长文件名、长路径会自动换行，所有按钮都在窗口宽度内看得到（「知识」页导入资料后被撑宽的问题修好了）

## 0.8.49

- 新增「客户」页：每个客户按你的每条业务分别记需求、预算、买过什么、到期时间，每条都标明出处。聊天里客户亲口说的会自动记下（性别、年龄、身体情况只记客户明说的；收入、宗教、政治、民族不记）
- 今日跟进：每天 9:30 列出该联系的客户（约好今天联系的、问过价没买的、快到期的、好几天没说话的），写好消息等你点「发送」；默认不自动发，只在白天发，每天有上限
- 导入老客户：表格拖进来自动认列；按分组给客户各写一条消息，你逐条看过再慢慢发
- 混群（默认关闭）：打开后，咔哒在没设免打扰的群里每天接两三句话，短、跟群有关、不发广告和链接。新群会弹提醒，可以直接点「这个群别管」。群里有人反感就停 7 天
- 自动更新的知识来源：在「知识」页添加 GitHub 仓库（私有仓库也行，借用电脑上已有的登录）或本地文件夹，按文件夹选用途（回复客户用 / 写法参考 / 内部参考）。空闲时每 6 小时自动更新，也可以点「立即更新」
- 手机找客户：线索表改成表格文件「门店线索.xlsx」，第一页「先联系这些」只放有电话的门店（手机号排最前），按行业、商圈、标签筛选；你填的跟进状态和备注不会被覆盖。点「打开线索表」直接打开
- 提醒卡片可以多一个选择按钮（比如「这个群别管」）

## 0.8.48

- 手机找客户（实验）：用插在电脑上的安卓手机在美团或大众点评上找门店，存成线索表（文稿/咔哒找客户/门店线索.csv）
- 第一步找门店：选 App、写搜索词，点「现在找一轮」
- 第二步补电话：去高德地图查门店电话，标出手机、座机、400 还是转接号
- 第三步加好友：用手机上的聊天软件加门店公开的手机号，每个号只加一次、每天有上限、只在白天加
- 风险提示：自动加好友有被平台限制的风险，建议先用小号、少量试；遇到验证码会自己停下，聊天软件提示「操作过于频繁」会自动停 48 小时
- Windows：本机识别聊天画面（实验）

## 0.8.47

- 保护密钥和隐私：有人来要 API Key、密码、验证码、后台账号、身份证号、银行卡号，咔哒礼貌拒绝、绝不发出；资料里写了也会自动隐藏
- 资料页会提醒你：哪些资料里有像密钥、密码的内容，建议删掉
- 你亲自发出去的密钥、验证码，不会被学进知识库

## 0.8.46

- 提醒卡片：开始接待时、咔哒要借用鼠标键盘时、客户等太久时，屏幕角落会弹出提醒，带「暂停接待」「知道了」「不再提醒」
- 「设置 → 提醒」：关掉的提醒可以重新打开
- 第一次用更安心：开自动回复、关审核、开群聊接待、开群同步、退出咔哒等重要操作前，先说清楚会发生什么再让你确定
- 新增「使用手册」：左边栏「帮助 → 使用手册」或右上角，常见问题放在最前面；问咔哒回答时也会给出手册链接

## 0.8.45

- 更省电脑：没有客户在等时，咔哒不再每秒截一次聊天窗口，改成先看一眼有没有新消息再决定。聊天软件和电脑都不会被拖卡
- 电脑内存紧张或发热时，咔哒自动放慢检查（回复慢几秒），并提醒你一次
- 空闲时每 3 秒看一次有没有新消息（原来 5 秒），有客户在聊时仍然半秒一次

## 0.8.44

- 回得更快：聊天画面本机看得清就直接用，不再每次都等 AI 模型。模型几秒不回就换备用模型，不再傻等 45 秒
- 资料多时不再先等「话题判断」：最多等 5 秒，之后直接按问题挑最相关的资料回复
- 锁屏、睡眠、聊天窗口暂时不见了，都不算你按了停止。窗口回来、解锁后自动接着接待，并提醒你一次
- 你在用电脑时，咔哒等你停手两三秒再进去回复。客户等了 2 分钟会提醒你，回复一定会补上
- 重启或装新版前没发出的消息，重启后自动重新读聊天再回，不再交给你处理
- 回复模型出错时，先换备用模型再试，都不行才提醒你
- 业务知识不再限制 20 条：可以用全部已审核资料，也可以只用勾选的（建议不超过 200 条）
- 每小时回复上限默认从 60 条提到 200 条，客户多的时候不再被卡住
- 手机接待（实验）：回聊天列表更稳，打字核对更严格，锁屏后自动恢复
- 新增「离线报警」（可选）：电脑睡着或断网 10 分钟，通过群机器人通知你

## 0.8.43

- 官网改版：更轻的配色，真实界面截图（示例店铺数据），按场景介绍功能，三步上手，四档价格

## 0.8.42

- 用手机接待：打完字核对输入框时，长回复只看得到一部分也能认出来，不再卡住不发
- 核对没通过时，只删掉咔哒自己打的字，然后回到聊天列表，不再一直盯着聊天页面反复识图

## 0.8.41

- 用手机接待：按头像上的红色数字判断新消息。红色数字就是新消息，小红点或免打扰铃铛才算免打扰

## 0.8.40

- 用手机接待：修好了「看到新消息却不回」。以前把带红色数字的新消息当成了免打扰，跳过了

## 0.8.39

- 用手机接待：记录每次看聊天列表的结果（只记有没有未读、是不是群，不记名字和内容），方便查为什么没回
- 打开文件夹里和文件夹同名的聊天软件也能认出来了

## 0.8.38

- 用手机接待：打开聊天软件改成像人一样点图标。桌面上有就点桌面上的，在文件夹里就打开文件夹再点，不会乱开别的分身
- 「识别手机上的聊天软件」现在能找全桌面和文件夹里的所有分身

## 0.8.37

- 新增「用手机接待（安卓，实验）」：手机插在电脑上，咔哒直接在手机里的聊天软件（包括应用分身）收消息、回复，不占电脑的鼠标键盘。默认关闭
- 提醒：用手机自动操作聊天软件可能被平台判定为异常，有封号风险，建议先用小号

## 0.8.36

- 营销内容的审核时间、发布时间可以选时区（例如「北京时间」），咔哒自动换算
- 配图：能用上你模型服务里的图片模型自动生成配图。今天已经写好、没配图的草稿会自动补上图

## 0.8.35

- 新增每天自动写营销内容：咔哒每天按你的资料写文案、从图片文件夹挑图，在你定的时间一起给你审。审过的按时间发，没审的不发。默认关闭
- 新增「群同步」（在「接待设置」里）：你在主群里发的文字消息，自动转到你选好的几个群。默认关闭
- 自动发布还在调试：到点会先把文案复制好，请你手动发

## 0.8.34

- 资料一股脑丢进来就能用：文件、整个文件夹、ZIP 压缩包、GitHub 或网页链接都行。咔哒自己整理成客户问答，整理完直接启用（「知识」页最上面的开关可以关掉）
- 和已有说法矛盾、或【】没填的，仍然等你决定
- 咔哒答不上来、你亲自回了客户之后，咔哒会把你的回答记进知识库，下次自己答
- 「开始」页改成三步：打开聊天软件、把资料丢进来、开始接待
- 接待运行中也能导入资料，不用先暂停
