# 第三步 开始接待

前两步做好了，点一下就能开始。

## 点开始接待

在「开始」页第三步点「开始接待」。也可以到「接待 → 运行」点「开始接待」，再点「确认开始接待」。

开始前咔哒会做一次体检。还差什么，会列出来，每一项后面都有「去处理」按钮：

- 屏幕录制权限、辅助功能权限
- 聊天软件已打开并登录
- 模型能连上
- 有自己的业务资料
- 软件试用次数或授权

全部打钩后就开始接待了。

## 开始以后会发生什么

- 咔哒的主窗口会让开，屏幕边上留一个小浮窗
- 客户发来消息，咔哒会点开聊天、写好回复、发出去
- 回完会把鼠标键盘还给你

小浮窗上能看到今天回了多少条、有没有等你确认的回复。

## 刚开始用，建议先审核

到「接待 → 接待设置 → 发送前审核」，选「每条都先给我看（刚开始用推荐）」。

这样每条回复都先给你看，你点「发送」才发出去。用顺手了再改成只审核退款、投诉、议价。详细看 [审核模式](#manual/review)。

## 接待页的四个标签

- 运行：开始、暂停、停止；今天收到、已回复、转人工的数量；待审核的回复；联系人设置
- 接待设置：聊天应用、接待范围、人设与语气、发送前审核、接待时段、管理员联系人、群同步、混群。最下面「更多设置（一般不用改）」
- 模型与回复：回复方式（自动回复或人工复制回复）、回复时参考哪些资料
- 窗口与校准：一般不用动。咔哒总是看错、点错位置时才用

## 接待范围

在「接待设置 → 接待范围」里选：

- 自动接待新消息（默认）：发现有未读消息就接待，不用提前填客户名单
- 只接待指定会话：只回你填的那几个人，适合先拿一个客户测试

默认只回没开免打扰的个人会话。群聊要勾上「同时接待未设免打扰的群聊」。

公众号、服务号这类通知，系统通知，名字不完整或认不准的，咔哒都会跳过。

## 接待时段

在「接待设置 → 接待时段（按客服时区）」里勾上「只在时段内自动接待，时段外自动暂停」，再选几点到几点、星期几。

不接待的时间不会调用模型，能省钱。

## 有客户需要你看一眼

咔哒拿不准、客户发了图片、或问到要你拍板的事，会转给你。

这些客户出现在「运行」页的「待处理客户」和小浮窗上。你回复完点「我处理好了」。客户再发消息时，咔哒自动接回。

## 每天小结

在「接待设置」填好「管理员联系人（异常通知）」，就是你自己另一个聊天账号的备注名。

需要人工、额度不足、每日小结，都会发到那个账号。没填时，在这台电脑上弹通知。
