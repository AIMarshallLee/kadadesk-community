# 手机接待（实验）

让咔哒通过数据线操作安卓手机上的聊天软件来接待客户。电脑的鼠标键盘不会被占用。

手机上的账号和电脑上的是两个账号，可以同时接待。

这是实验功能，默认关闭，只支持安卓手机。

> 用手机自动操作聊天软件可能被平台判定为异常，有封号风险，建议先用小号。

## 第一步 插上手机并允许 USB 调试

1. 在手机「开发者选项」里打开「USB 调试」
2. 再打开「充电时屏幕不休眠」。咔哒不会自己点亮或解锁手机
3. 用数据线插到电脑上，在手机弹窗里点「允许」
4. 到咔哒「设置 → 用手机接待（Android，实验）」，点「检测手机」

提示还没找到 adb：Mac 可以在「终端」运行页面上写的那行命令安装。

## 第二步 识别手机上的聊天软件

点「识别手机上的聊天软件」。

咔哒会依次打开这个聊天软件的每一个分身，认出它们分别是哪一个，最后回到手机桌面。只在你点按钮时才会这样做。

## 第三步 勾选要接待的，然后开始

勾选要接待的那几个，点「开始用手机接待」。要停就点「停止」。

每一个都会显示状态和今天回了几条。

## 手机接待时要注意

- 不要在手机上同时操作这个聊天软件。你一动手机，咔哒这一轮就先停下
- 接待规则、知识库、联系人设置都和电脑上的接待一样
- 急停也会停下手机接待
- 手机锁屏后，解锁回来会自动恢复

## 手机找客户（实验）

用插在电脑上的安卓手机，在美团或大众点评上找附近的门店，整理成一张线索表；还可以去高德地图查门店电话，再用手机上的聊天软件加商家好友。在「设置 → 实验功能」，「用手机接待」下面的「手机找客户」卡片里。

先准备好：手机已经在「用手机接待」第一步认出来；手机上装好美团（或大众点评）并登录，城市选成你要找客户的城市；要补电话的话装好高德地图；找客户时手机放着别动，屏幕保持亮着。

第一步：找门店。在「在哪个 App 上找」选美团或大众点评，「搜索词」一行写一个（比如「口腔」），设好「每轮最多找几家」，点「现在找一轮」。找到的门店存进「文稿/咔哒找客户/门店线索.xlsx」，点「打开线索表」直接打开（用 Numbers、Excel 或 WPS）。

线索表怎么看：

- 第一页「先联系这些」：只放查到电话的门店。A（绿色）是手机号，最好打；B（黄色）是座机或 400
- 「全部门店」：所有找到的门店，可以按行业、商圈、标签、跟进状态筛选。标签有：有手机号、在投广告、有团购、千条评价、高分、分店/连锁等
- 联系过之后改「跟进状态」（下拉选择），也可以写「下次跟进」和「备注」。咔哒下次找客户时会读回这三列，不会覆盖。找客户时请先保存并关掉这张表
- 「按行业统计」：每个行业找到多少家、多少家有手机号、联系了多少家

第二步：补电话。勾上「找到门店后去高德地图查电话」，咔哒会去高德地图搜每家店，把电话记进表里，并标出是手机、座机、400 还是转接号。

第三步：加好友。勾上「查到手机号后……主动加商家」那一项，选好用哪个号，设好「每天最多加几个」。只加门店公开的手机号，每个号只加一次，只在 9:30–20:30 之间加，每次间隔几分钟。好友申请会带上店名，并写明是谁的助理。

> 风险提示：自动加好友有被平台限制的风险。建议先用小号、每天少加几个。咔哒遇到验证码、滑块或安全验证会自己停下，不会替你过验证；聊天软件提示「操作过于频繁」会自动停 48 小时。只记录门店公开信息，不打电话。
