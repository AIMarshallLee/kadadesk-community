# 咔哒会借用鼠标键盘

第一次看到鼠标自己在动，很多人会吓一跳。别慌，这是咔哒在替你回客户。

## 为什么要借用

咔哒是像人一样用聊天软件的。它要：

- 点开有新消息的聊天
- 把写好的回复打进输入框
- 点「发送」

这些都要用到鼠标和键盘。所以接待时，你会看到鼠标自己移动、聊天窗口跳到前面、输入框里自己出现文字。

每次只借几秒，回完马上还给你。

## 看到鼠标自己动，不要慌

- 这是正常的，不是中毒，也不是别人在远程控制
- 小浮窗上会写「咔哒正在操作」，旁边写着急停快捷键
- 不想让它动，按急停就行，详细看 [暂停与急停](#manual/pause-stop)

## 你一动，它就让开

你也要用这台电脑，没关系：

- 你在打字或动鼠标时，咔哒不会进去。它等你停手两三秒才开始
- 你在别的软件里打字，咔哒至少等你停手 3 秒，免得把你打的字打进聊天窗口
- 咔哒正在动鼠标时你一抢，它马上让出控制，等你停下再来
- 小浮窗这时会写「等你停手」

回复不会丢。写好的回复会留着，等你停手再发。发之前会再核对一遍聊天。

客户等了 2 分钟，咔哒会提醒你：你停手 2 秒，它就把回复发出去。

## 想安心用电脑一会儿

- 按暂停快捷键：Mac 是 ⌃⌥K，Windows 是 Ctrl+Alt+K。用完再按一次继续
- 或者点小浮窗上的「暂停接待」

暂停时客户的消息不会自动回复。记得用完继续。

## 小浮窗挡住了怎么办

小浮窗可以拖到桌面任何地方。

拖到屏幕左边或右边，它会缩进去只露一条细边，鼠标移过去就滑出来。

放在聊天窗口上也没关系，咔哒点按、打字那几秒，它会自动让开。

## 某个按键好像一直按着

用远程控制软件时，断线后电脑可能以为某个键一直按着。咔哒会以为你在打字，一直等。

这时咔哒会提醒你是哪个键。在键盘或远程控制软件里按一下那个键就好。
