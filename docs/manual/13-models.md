# 模型设置

模型就是咔哒的「大脑」：一个负责看懂聊天窗口，一个负责写回复。

新装的咔哒已经接好免费试用模型，什么都不用填就能先用。这一章讲以后想换模型时怎么做。

## 免费试用模型

- 新装好就能用，不用填密钥
- 前一部分回复免费，「开始」页和「设置 → 一键配置模型」里会写具体条数
- 免费条数和软件试用次数分开算
- 免费试用模型连不上时，一般过几分钟会恢复，点「刷新」再看

免费条数用完，或想用自己的模型，就按下面的办法配。

## 一键配置

到「设置 → 一键配置模型」，三种办法任选一种。看屏幕和写回复会一起配好。

### 用咔哒内置模型（最省事）

点「一键开通」，不用填任何东西。用量从你的账户余额里扣。

### 导入配置文件

服务人员给了你一个配置文件或一段配置文字：

- 点「选择配置文件」，选中它
- 或点「粘贴配置文字」，把整段粘贴进去，点「导入」

提示这个配置不含密钥时，粘贴你自己的 API Key，再点「用这个 Key 导入」。

### 选服务商 → 粘贴 Key → 一键配好

1. 在服务商列表里点一家（可以在搜索框里搜名字）
2. 点卡片上的官网链接，注册登录，在控制台找「API Key」或「密钥」，新建一个并复制。要充值的先充一点
3. 把 Key 粘贴进「粘贴 API Key」
4. 点「一键配好」

咔哒会自己列出模型、挑好看屏幕和写回复的模型，再用一张测试图片试一下。

## 看结果

- 「已配好…图片测试通过」：可以去开始接待了
- 「还差一步：请粘贴 API Key」：没填 Key
- 「没通过服务商验证」：Key 不对，或账号没充值、没开通
- 「没认出合适的模型」：点「自己指定模型名」，从服务商后台复制模型名称填进去，再点一次

## 常见报错

- 密钥认证失败（HTTP 401）：Key 没复制完整、多了空格，或选错了服务商
- 模型访问被拒绝、模型名称不对（HTTP 403 / 404）：账号没开通这个模型，尤其是能看图的模型
- 额度不足或调用受限（HTTP 429）：余额不够，或调用太频繁被限流
- 模型服务繁忙（HTTP 503）：过几分钟再试

## 备用模型和自动挑选 {#backup}

点「高级：用自己的模型（一般不用管）」能看到这些。

- 自动挑选模型：默认开着。咔哒在你这家服务里找出其他能看图的模型，按速度轮流用。哪个被限流就让它歇一会儿
- 备用模型：选一家和主模型不同的服务商，填接口地址、能看图的模型名称和 Key，点「保存为备用模型」，再点「测试备用模型」

主模型被限流、没响应或连不上时，咔哒自动换用备用模型，过几分钟再试回主模型。回复模型出错时，也是先换备用模型再试，都不行才提醒你。

## 模型费用

咔哒软件本身不含模型费用（内置模型版除外）。模型按用量计费，在服务商那里充值，用多少扣多少。

省钱办法：

- 在「接待设置」里设好接待时段，不接待的时间不会调用模型
- 在「接待设置 → 更多设置」里填一个便宜的模型，用来做找会话、读列表这些简单的活

## 密钥安全

密钥加密保存在这台电脑上，不会显示出来。不要把密钥发在聊天里。
