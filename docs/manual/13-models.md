# 模型设置

大模型是咔哒知识问答、回复草稿生成与意图分析的计算引擎。

咔哒社区版不附带任何内置商业密钥或私有中转地址。用户可配置国内外主流模型服务商的 API Key，或接入本地运行的模型服务（如 Ollama、LM Studio、vLLM）。

## 配置模型

前往「设置 → 模型设置」，可通过以下方式快速接入：

### 方式一：选择服务商并填写 API Key

1. 在主流模型服务商列表（如 DeepSeek、通义千问、Kimi、GLM、OpenAI、Anthropic 等）中选择所需服务。
2. 前往对应服务商开放平台注册并创建 API Key。
3. 将 API Key 粘贴到输入框中，并选择或填入模型名称（例如 `deepseek-chat`、`qwen-plus` 等）。
4. 点击「验证连接」，通过后点击「保存」。

### 方式二：接入本地或私有兼容接口（OpenAI 协议）

1. 服务商选择「自定义 / 兼容 OpenAI」。
2. 填入接口地址（Base URL，例如 `http://localhost:11434/v1`）。
3. 填入模型名称及 API Key（本地模型服务可填任意非空字符串）。
4. 验证并保存。

### 方式三：导入配置

支持通过 JSON 配置文件或文本一键导入预设参数，便于在多台设备间快速分发统一配置。

## 备用模型保障 {#backup}

为了防止单家服务商因欠费、限流（HTTP 429）或上游故障导致服务中断，咔哒支持配置「备用模型」：

1. 在模型设置页面展开「备用模型」。
2. 建议选择与主模型不同厂商的服务（例如主模型用 DeepSeek，备用模型用通义千问）。
3. 保存并测试连接。
4. 当主模型请求超时或返回限流错误时，系统将自动无缝降级至备用模型，确保业务草稿不中断。

## 常见报错排查

- HTTP 401（认证失败）：API Key 错误、存在多余空格或已过期。
- HTTP 403 / 404（访问受限 / 模型不存在）：账户未开通该模型权限，或填写的模型名称有误。
- HTTP 429（超出配额 / 请求受限）：模型账户余额不足或超出并发限制。
- HTTP 500 / 503（服务故障）：服务商临时故障，系统会自动切换至备用模型。

## 密钥与凭证安全

API Key 仅加密保存在当前电脑本地，不会上传至任何第三方服务器。请妥善保管您的密钥，避免在公开代码或聊天中泄露。
