# 更新

咔哒会经常出新版本，修问题、加功能。每个版本改了什么，看 [更新记录](#manual/changelog)。

## 自动更新

到「设置 → 版本与更新」。默认开着「自动下载新版（推荐）」：

- 打开咔哒时，以及每 6 小时，检查一次有没有新版本
- 有新版本就在后台下载、核对好
- 你在电脑前时，点「现在更新」才安装

为什么要你点：装完 Mac 会问一次录屏权限，没人点「允许」就没法接着接待。

## 现在更新

1. 到「设置 → 版本与更新」，点「现在更新」
2. 咔哒会自己关掉再打开，大约半分钟
3. 系统问录屏权限时，点「允许」

正在回客户时，咔哒会说明在等什么，忙完马上装。接待会接着进行。

装新版前没发出去的消息，重启后会自动重新读聊天再回。

## 手动下载

出现「下载」按钮时，点它下载新版：

- Mac：先关掉咔哒，打开下载的文件，把新的咔哒拖进「应用程序」替换旧的
- Windows：先关掉咔哒，把压缩包解压，用新的咔哒文件夹替换旧的。第一次打开出现「Windows 已保护你的电脑」时，点「更多信息 → 仍要运行」

数据和设置都存在电脑里，不会丢。

## 当前版本

「设置 → 版本与更新」里写着「当前版本」。「使用手册」页最上面也写着。

## 开机自动打开咔哒

在「设置 → 版本与更新」里打开「开机自动打开咔哒（推荐）」。电脑重启后咔哒自己回来，不会因为没人点开而停了接待。

只有上次退出前在接待、并且开了自动恢复时，才会自动接着接待。
