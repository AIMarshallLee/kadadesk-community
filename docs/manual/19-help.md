# 遇到问题找谁

## 第一步：看手册

先看 [常见问题](#manual/faq)。也可以在「使用手册」页上面的搜索框里写几个字。

各个页面上还有「小教程」，一步一步教你。

## 第二步：问咔哒

点顶部的「问咔哒」，用一句话说你想做什么、卡在哪里。

问咔哒只回答怎么用咔哒。它会告诉你去哪里、点什么，还会给你一个按钮直接带你过去。它不会替你改设置。

## 第三步：生成求助包与诊断

1. 点顶部「帮助与日志」
2. 点「一键生成求助包」或查看本地诊断日志
3. 求助包会打包本地错误日志与脱敏环境信息

## 第四步：提交 GitHub Issues

如遇到 Bug、异常或有功能建议，欢迎到 GitHub 提交 Issue：

- 访问仓库：[GitHub Issues](https://github.com/AIMarshallLee/kadadesk-community/issues)
- 提交时请附带：操作系统版本、出现问题的具体步骤、错误提示及求助包日志（请确认已脱敏）。
