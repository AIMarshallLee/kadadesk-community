# 遇到问题找谁

## 第一步：看手册

先看 [常见问题](#manual/faq)。也可以在「使用手册」页上面的搜索框里写几个字。

各个页面上还有「小教程」，一步一步教你。

## 第二步：问咔哒

点顶部的「问咔哒」，用一句话说你想做什么、卡在哪里。

问咔哒只回答怎么用咔哒。它会告诉你去哪里、点什么，还会给你一个按钮直接带你过去。它不会替你改设置。

## 第三步：生成求助包

1. 点顶部「帮助与日志」
2. 点「一键生成求助包」
3. 文件在「下载」文件夹里，咔哒会帮你打开它所在的位置

也可以点「反馈问题」，写一句刚才发生了什么。

## 第四步：联系客服

把求助包发给客服：

- 客服：kadadesk_support
- 邮箱：Marshall@kunlungrowth.com

说清楚：什么时候、在哪个页面、点了什么、看到了什么提示。
