# 第二步 导资料

咔哒照着你的资料回答客户。资料越全，答得越准。

## 先打开聊天软件

在这台电脑上打开要接待客户的聊天软件，扫码登录好。

咔哒会自己找到聊天窗口。开始页第一步显示「已找到聊天窗口」就好了。

没找到，或开了好几个聊天软件：点「去选择窗口」，在「接待 → 窗口与校准」里点「列出应用窗口」，选你要的那个。

## 把资料丢进来

1. 点左边的「知识」，进入「导入与试答」
2. 把手头所有资料一股脑拖到「把所有资料一股脑拖到这里」的框里
3. 点「开始整理」
4. 等整理完。资料多的话要几分钟，可以先去做别的，别关咔哒

能丢什么：

- 文件：PDF、Word、Excel、CSV、TXT、Markdown、网页
- 整个文件夹、ZIP 压缩包
- 链接：GitHub 仓库或网页地址，贴在「有 GitHub 仓库或网页？把链接贴在这里」下面，一行一个。私有仓库、或者资料会经常更新的，用下面的「自动更新的知识来源」，看 [自动更新的知识来源](#manual/knowledge/auto-sources)
- 直接粘贴文字

一次最多 300 份。单个文件不超过 8MB。读不出来的文件会列出来跳过，不影响别的。

## 整理完会怎样

咔哒会把资料拆成一条条客户问答，分好类。

「知识」页最上面有个开关：「咔哒整理好的知识直接用来回复客户（推荐）」。

- 开着（默认）：整理完就能用
- 关掉：整理好的知识要你勾选确认才会用

不管开没开，这几种都要你确认：同一个问题答案不一样的、【】没填的、内部资料。

## 试问一句

整理完，页面会请你「试问一句」。写一句客户真会问的话，点「试答」。

只在这里试，不会发给客户。答得不对，就去改那条知识，详细看 [知识库](#manual/knowledge)。

## 手头没有资料

点「没有现成资料？选个行业样板，把【】换成你的信息」。

选一个接近你生意的行业，把【】里的地方换成你自己的信息。样板要你确认后才会用。

资料导好了，去 [第三步 开始接待](#manual/start)。
