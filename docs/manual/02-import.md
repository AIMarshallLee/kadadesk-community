# 怎么把资料丢进来

咔哒照着你的资料回答与生成草稿。资料越全，答得越准。

## 把资料丢进来

1. 点击左侧导航栏的「知识」，进入「导入与试答」。
2. 将手头的业务资料拖拽至「快速导入」区域。
3. 点击「开始整理」。
4. 稍等片刻，系统会调用本地解析引擎进行分块、提炼并录入。

支持导入的文件类型：

- 文件：PDF、Word、Excel、CSV、TXT、Markdown、HTML
- 整个文件夹、ZIP 压缩包
- 链接：GitHub 仓库或网页地址，贴在输入框中，一行一个。经常更新的仓库可使用「自动更新的知识来源」，看 [自动更新的知识来源](#manual/knowledge/auto-sources)
- 直接粘贴纯文本问答

一次建议不超过 300 份文件，单个文件尽量在 8MB 以内。纯图片扫描型文件建议先用 OCR 识别提取文本。

## 整理完毕与审核

系统解析后，会将资料拆分成结构化的知识条目与标签。

- 默认情况下，整理好的知识条目可以直接用于试答与草稿生成。
- 如果存在矛盾问答、内部机密提醒或带占位符的内容，系统会标黄高亮，等待人工确认审核。

## 试问一句验证

整理完成后，在页面下方的「试问一句」输入框输入常见客户提问，点击「试答」。

可以在右侧查看系统命中的知识条目与生成的回答。如果不满意，可点击直接修改条目。

## 手头没有现成资料

点击「没有现成资料？选个行业样板，把【】换成你的信息」。

选择接近你业务场景的行业样板（如电商零售、企业服务、咨询培训等），将占位符替换为你真实的产品与售后政策即可。
