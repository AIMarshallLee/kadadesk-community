# 离线报警

电脑睡着、断网或咔哒退出 10 分钟，咔哒会通过群机器人通知你。这样你不在电脑旁边，也知道咔哒停了。

这是可选功能，默认关闭。

## 怎么打开

1. 在你的办公群里打开 群设置 → 群机器人 → 添加机器人，复制它的 Webhook 地址
2. 到咔哒「接待 → 接待设置」，找到「管理员联系人（异常通知）」下面的离线报警
3. 填「这台电脑的名字」，比如「店里 Mac」
4. 把 Webhook 地址粘贴进「群机器人地址」
5. 点「发一条测试」，到群里看有没有收到
6. 勾上「离线报警：电脑睡着、断网或咔哒退出 10 分钟时，通知我」

## 会发什么

只发电脑名字和在线状态，不发客户消息。

## 地址格式不对

要复制群机器人设置里完整的 Webhook 地址，不要只复制一部分。

页面上会显示「上次心跳成功」的时间。出错时会写明上次出错的原因。
