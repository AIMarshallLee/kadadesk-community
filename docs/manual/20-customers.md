# 客户档案与跟进

「客户」模块帮助店主在本地井井有条地管理客户档案与跟进生命周期：记录业务阶段、客户需求、购买记录与跟进提醒。

所有客户档案仅保存在当前设备本地，不上传云端，确保私域客户资产安全。

## 客户档案记录的信息 {#what-is-recorded}

每位客户拥有独立的结构化档案：

- 基础信息：姓名/昵称、行业、城市、联系方式、标签与备注。
- 业务线关联：当前所处跟进阶段（如初访、方案沟通、报价、已成交、复购维护等）、需求要点、预算与意向等级。
- 购买记录：已购产品、成交金额、购买日期及订阅/服务到期日。
- 待跟进计划：预约跟进时间与跟进事项。

敏感信息护栏：系统绝不记录与业务无关的敏感隐私数据（如个人银行卡号、身份证号、口令等）。

## 业务线管理 {#business-lines}

若企业涵盖多项业务或产品形态，可在「客户 → 业务线」中自由定制：

- 自由配置各业务线的生命周期阶段（支持自定义阶段流转）。
- 维护各业务线的标准产品与服务价格参考。
- 自定义字段扩展（例如门店规模、偏好交付方式等）。

## 档案检索与分组维护 {#edit-profile}

1. 进入「客户」页面。
2. 可按业务线、跟进阶段、意向度、标签或关键词进行多维度过滤与检索。
3. 点击客户条目查看与修改档案详情。
4. 支持保存筛选条件为「自定义分组」，方便针对不同客群分类梳理。
5. 支持一键导出筛选后的客户清单为 CSV 表格。

## 今日跟进清单与草稿生成 {#follow-up}

系统每天会自动扫描本地客户档案，整理今日待跟进清单：

- 预约跟进：到达预约回访日期的客户；
- 到期提醒：服务或订阅即将到期（如提前 30 天、7 天）的存量客户；
- 阶段停滞唤醒：报价或咨询后多日未互动的意向客户。

**跟进草稿复制模式**：
- 针对待跟进的客户，咔哒可调用大模型并结合客户档案与业务知识，自动生成个性化的跟进建议草稿。
- 社区版不设任何聊天窗口自动打字与自动发送行为：店主或运营人员直接点击「复制草稿」，在自己的聊天窗口中手动粘贴、审阅后发送。

## 批量导入与数据备份 {#import}

- 客户表格导入：支持将外部 Excel / CSV 文件导入，可视化映射姓名、电话、业务线、购买时间等列名，重复客户自动合流去重。
- 本地快照备份：客户数据随整库备份导出为 `客户档案.json`，可随时迁移与离线归档。
