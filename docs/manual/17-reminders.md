# 提醒与「不再提醒」

咔哒有事要告诉你时，会在屏幕角落弹出一张提醒卡片。卡片上来不及显示时，会改用系统通知。

## 会提醒哪些事

- 开始接待时：说明咔哒会借用鼠标键盘
- 你在用电脑、咔哒等你停手发回复时
- 客户等了 2 分钟还没回上
- 有客户需要你看一眼
- 聊天窗口不见了，或需要扫码登录
- 系统在问能不能录屏
- 电脑内存紧张或发热，咔哒放慢了
- 回复模型出问题，换用了备用模型
- 回复模型连续出错
- 用快捷键暂停或继续接待
- 咔哒转到后台运行
- 某个按键好像一直按着
- 知识来源自动更新了，或者没更新成功

同一类提醒短时间内不会重复弹。

## 卡片上的按钮

有的卡片上有「暂停接待」或「打开咔哒」，点了就直接做。点「知道了」只关掉这一张，不点它十几秒后也会自己收起。

不想再看到这一类提醒，点「不再提醒」。以后这一类就不弹了，升级到新版也一样。

重要的提醒（比如客户在等、有客户需要你看一眼）点「不再提醒」时，咔哒会再问你一次，免得漏了客户。

## 想把提醒找回来

到「设置 → 提醒」。被你关掉的提醒都列在这里，可以一个个重新打开。软件页面里点过「不再提醒」的小提示，也可以在这里全部重新显示。
