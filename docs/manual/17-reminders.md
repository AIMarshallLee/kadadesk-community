# 提醒中心与偏好

咔哒在后台运行或检测到重要状态变化时，会在工作台或系统托盘中给出轻量提示。

## 常见提醒类型

- 知识来源更新提醒：GitHub 仓库或本地目录完成自动增量同步，或同步连接失败。
- 模型降级与故障告警：主模型超时、限流或不可用，系统自动切换至备用模型。
- 今日待跟进提醒：根据设定的客户跟进计划，提醒今日需要触达的重点客户。
- 敏感信息护栏拦截：导入文档或生成草稿中识别出高危敏感信息（如 API Key、密码等）。
- 本地运行诊断提示：磁盘空间不足或配置异常等诊断警示。

同一类通知在短时间内会自动合并，防止打扰。

## 提醒卡片操作

- 点击卡片上的操作按钮可直接前往相关页面（如查看同步明细、切换模型设置等）。
- 点击「知道了」关闭当前提醒。
- 如果不希望某类提醒频繁出现，可点击「不再提醒」。

## 恢复已忽略的提醒

前往「设置 → 提醒与偏好」：

- 可以查看所有被关闭的提醒类型列表；
- 点击「恢复显示」即可随时重新启用提醒。
