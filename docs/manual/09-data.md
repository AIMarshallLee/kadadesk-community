# 数据与统计

咔哒社区版所有数据均存储在本地设备中，提供实时的知识库资产与客户跟进统计。

## 统计概览

在「知识」与「客户」模块中，可实时查看：

- 知识库规模：已导入与已启用的问答条目总数、知识来源数量及分类分布。
- 客户档案统计：录入客户总数、各阶段跟进漏斗分布（潜在、咨询、报价、成交等）。
- 今日待跟进：当天需要人工跟进、复联的客户清单与待处理任务。

## 数据存储位置

- 咔哒的数据完全保存在本地磁盘（SQLite 数据库与本地文件缓存目录中）。
- 不会向任何远端服务器上传客户列表、聊天记录或业务知识。

## 数据备份与导出

在「知识 → 管理资料」与「设置 → 备份与迁移」中：

- 支持将全部知识条目一键导出为标准的 JSON 或 ZIP 归档包。
- 支持将客户档案导出为 CSV / Excel 兼容文件，方便与外部 CRM 协同。
- 建议定期将备份文件同步至企业私有云盘或离线介质。
