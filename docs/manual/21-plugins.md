# 插件与扩展

咔哒支持通过插件扩展连接更多外部能力与数据底座。

## 连接增长飞轮 {#flywheel-connect}

### 它做什么
把咔哒客户档案里发生的事，发到你的增长飞轮「事件中心」（按 `flywheel.v1` 规范，用你自己搭的或你信任的服务），让看板和 CRM 看得到；同时把别处先认识的客户、扣词表和销售进展收回来，起草回复时用上。

社区版不读、不写任何聊天窗口，所以发出去的事件来自咔哒的核心功能：

- **发出去的**：你在客户档案里改了的画像 7 项（意向、行业、城市、需求、预算、打算什么时候买、是不是拍板的人）。如果你给咔哒接了自己的接待事件来源（按插件事件约定发事件），还会发：客户什么时候来消息、第一次回复用了几秒、是咔哒回的还是你回的；转人工的原因（只是一个分类，比如「问价」「发了图片」）；客户从哪来（发了哪个扣词）。
- **收回来的**：扣词表（客户第一句话发扣词时，咔哒知道他是看了哪条内容来的，并在档案「来源」里记下）；别处先认识的客户（预建档案，标「未接触」）；销售进展（报价中、已成交……起草回复时不再当新客户从头介绍）。

### 怎么打开
1. 左侧菜单「插件」→「咔哒内置插件」里找到「连接增长飞轮」，点「安装」→「同意并安装」。装好后是**关着的**。
2. 在它的卡片上填「事件中心地址」（要用 `https://`，只有本机测试地址可以用 `http://`），粘贴「密钥」，点「测试连接」，看到「连接成功」后点「保存」。密钥只加密保存在这台电脑上（系统的加密存储），页面上只显示「已加密保存」；这台电脑没有加密存储时，密钥不能保存，咔哒也不会把它明文写在电脑上。
3. 「工作区编号」按事件中心给你的填（默认 `default`）。
4. 点「打开」，看确认卡上写的「会发什么、永远不会发什么、会收回什么」，点「我知道了，打开」。
5. 四个开关可以单独关：发送接待事件 / 发送客户画像 / 接收别处来的客户 / 接收销售进展。

### 发什么、不发什么
- **聊天原文一个字都不发**：客户说的话、咔哒和你的回复都不发；转人工只发原因分类，不发话题；画像不发原话引用。
- **敏感信息不发**：性别、年龄、身体情况这类标了敏感的内容不发。文字里出现手机号、身份证号、银行卡号会先打码（例如 138****0000），密码、验证码这类保密信息会被隐藏。
- **身份信息只在客户主动联系过你时带**：备注名，以及客户自己给你的手机号等。你手动录入或导入、还没联系过的客户，只发咔哒的档案编号。
- 每一条发出去之前都会按 `flywheel.v1` 统一格式检查一遍，格式不对的不会放进发件箱，记在「出错」里。

### 卡片上的数字
- **已发送 / 待发送 / 需要处理 / 出错 / 最后一次成功**。
- 事件中心连不上或暂时出错（5xx）时，事件先存在这台电脑上，咔哒按 1 分钟、5 分钟、30 分钟、2 小时、之后每小时自动重试；事件中心说「太频繁」（429）时按它要求的时间（Retry-After）再发。
- 密钥不对或没有权限（401/403）：卡片上写「密钥不对」，先暂停发送，重新粘贴密钥后自动继续，事件不会丢。
- 事件中心不收的（其他 4xx，或回执里写了拒收）：放进「需要处理」，写明原因，不会自动重发，可以点「重新发送」或「删掉」。
- 已发送的记录在电脑上保留 30 天，方便排查。

### 别处来的客户
- 和档案里的客户手机号、聊天软件账号、平台用户编号等能确认身份的信息一样：合并到这位客户，记下来源和需求。
- 只是名字一样：咔哒**不合并**，在卡片上提示「可能是同一位客户」，你点「是同一人」「不是」或「忽略」。
- 都对不上：新建一个档案，标「未接触」。
- 事件中心认出是同一人后（同一个客户编号，或手机号等一样），咔哒把预建的「未接触」档案并进已经联系过的档案，来源、需求和记录都保留，销售进展也记在这个档案上。两个档案都联系过时不自动合并，在卡片上请你确认。
- 拉取别处的客户用事件中心给的游标接着拉，咔哒原样保存、原样带回，不会重复导入。

### 开放接口（MCP）
打开插件后，开放接口多两个只读工具：`customers_get`（档案摘要：行业、城市、来源、业务阶段、意向、需求、预算、时间、销售进展）和 `reception_events_since`（事件摘要：类型、时间、渠道、用时、原因分类、变化的画像字段名）。都不含名字、电话、聊天软件账号等身份信息，不含敏感信息和原话；只给你在「开放」页勾了「可以修改设置」的客户端，插件关着时不列出也不响应。

### 怎么关掉
在卡片上点「关闭」，马上停止收发（正在发的会中断）。还没发出去的事件留在电脑上，可以点「一键清空待发」。卸载插件时，密钥、确认记录和待发事件一起删掉。

### 现在还做不到
- 社区版没有聊天接待，「首次回复」「转人工」这类事件只有在你自己接了接待事件来源时才会有。
- 发件箱和客户档案是分开的文件，电脑在那一瞬间断电，可能少记那一刻的事件。
