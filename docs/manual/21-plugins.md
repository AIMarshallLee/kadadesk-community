# 插件与扩展

咔哒支持通过插件扩展连接更多外部能力与数据底座。

## 连接增长飞轮 {#flywheel-connect}

### 它做什么
「连接增长飞轮」是官方提供的数据打通插件，用于将咔哒的接待能力与增长飞轮数据底座（`flywheel.v1` 规范）进行双向连接：
- **事件安全出站**：将进线、首响速度、转人工原因、客户画像变更、新留资建档与每日稳定性健康日报，以标准化事件信封投递至事件中心。
- **数据智能入站**：定时拉取全网推广扣词表，自动识别客户首句来源并在接待时为 AI 提示引流活动背景；拉取多渠道外部线索预建档案；同步销售成单及阶段进展并提示在接待上下文与客户卡片中。

### 怎么配置
1. 打开左侧菜单「插件」，在官方推荐列表中找到「连接增长飞轮」，开启插件。
2. **事件中心地址**：填写统一事件接入网关地址（例如 `https://flywheel.example.com` 或你自己部署的事件中心）。
3. **接口密钥**：填写分配给本店的 API 访问令牌（保存在系统钥匙串中，界面脱敏显示）。
4. **工作区 ID**：所属企业工作区标识（默认 `kunlun`）。
5. **细粒度同步开关**：可按需单独开启或关闭「上报接待与进线事件」、「上报客户画像更新」、「接收外部线索预建档案」、「同步销售阶段与进展」。
6. 点击「测试连接」，显示「连接成功，服务运行正常」后点击保存。

### 安全与隐私红线（发什么、绝不发什么）
- **绝不发送**：客户聊天原文、对话上下文记录、敏感个人信息（银行卡号、密码、身份证号等）；所有出站文字强制经过本地 `secret-guard` 自动扫描脱敏。
- **只发送**：事件信封（事件 ID、时间戳、脱敏联系人标识）、响应延迟时长、转人工归因类别、白名单画像属性（如预算区间、行业、意向等级）。
- **零打扰机制**：插件为完全后台静默运行。当客户正在等待回复、系统正在接待或电脑资源紧张时，网络通信严格暂停避让，绝不争抢系统输入与网络资源。

### 离线与网络故障
- 遇到断网或服务器维护时，事件自动暂存在本地发件箱（`outbox.jsonl`）中，绝不丢失。
- 网络恢复后自动批量补发；若服务端出现临时错误（5xx）会自动按 1分钟、5分钟、30分钟 指数退避重试；4xx 永久错误自动归档丢弃，避免队列堵塞。

### 怎么关掉
在「插件」页面，找到「连接增长飞轮」设置卡片，将顶部的总开关关闭即可完全停止所有出站上报与后台同步。
