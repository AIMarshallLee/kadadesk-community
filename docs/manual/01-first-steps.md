# 装好以后第一步

咔哒是装在电脑上的 AI 客服。它看着你已经登录的聊天软件，照着你的资料回复客户。

用起来只要三步：打开聊天软件、把资料丢进来、点开始接待。这一章先讲打开咔哒和给权限。

## 打开咔哒

- Mac：在「应用程序」里双击「咔哒」
- Windows：双击咔哒文件夹里的 kadadesk

第一次打开会进入「开始」页。页面上写着「开始：0 / 3」这样的进度。每做完一步会自动打钩。

左边是导航：开始、知识、接待、数据、营销、插件、设置、开放。新手只用前三个就够了。

## 开始页怎么看

开始页一共三步：

1. 第一步：打开聊天软件
2. 第二步：把资料丢进来
3. 第三步：开始接待

模型还没接好时，中间会多一步「接好模型」。新装的咔哒已经接好免费试用模型，一般不会出现这一步。

每一步下面都有按钮，点它就带你去该去的地方。做完了点「刷新」再看一次。

## 为什么要给两项权限 {#permissions}

Mac 上咔哒需要两项权限。Windows 电脑不用这一步。

- 录屏（系统里叫「录屏与系统录音」，旧版系统叫「屏幕录制」）：咔哒要看见聊天窗口，才知道客户说了什么
- 辅助功能：咔哒要点开聊天、打字、点发送，才能替你回复

咔哒只看你的聊天窗口，不会自动批准权限。每一项都要你自己在系统设置里打开。

## 怎么点允许 {#allow}

1. 在「开始」页最上面的「Mac 第一次使用：先允许两项权限」里，点「允许屏幕录制」
2. 系统会打开「系统设置 → 隐私与安全性 → 录屏与系统录音」。找到「咔哒」（也可能写着 kadadesk），打开开关
3. 系统提示「退出并重新打开」时，点它。咔哒会自己重新打开
4. 回到「开始」页，点「打开辅助功能设置」
5. 在「隐私与安全性 → 辅助功能」里，同样打开「咔哒」的开关
6. 回到咔哒，点「重新检查权限」。两项都显示「已允许」就好了

> 系统要求输入电脑密码或按指纹，是正常的。这是系统在确认是你本人在改设置。

## 以后还会问录屏吗

会。接待中，Mac 系统隔一段时间会弹窗问「是否允许咔哒录屏」。直接点「允许」就行。

更新到新版以后，系统也会再问一次。同样点「允许」。

## 使用时的几个习惯

- 保持电脑登录，不要锁屏，不要睡眠
- 聊天软件保持打开，不要最小化
- 聊天窗口大小定好以后，尽量别再拉伸或最大化。咔哒记住位置后回得更快、更省钱
