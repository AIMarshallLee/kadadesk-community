# 装好以后第一步

咔哒社区版是运行在本地的企业私域 AI 知识与客户工作台。所有数据均存储在本地设备，确保数据资产与隐私安全。

开启使用只要三步：配置模型、导入知识资料、试答验证。

## 打开咔哒

- 桌面版：运行编译生成的应用或执行 `npm run desktop`。
- 网页开发版：终端执行 `npm run dev` 后在浏览器访问对应本地端口。

左侧主导航包含：知识、客户、开放、插件、设置。

## 第一步：配置大模型

社区版不附带任何内置商业密钥或私有中转，请使用您自己的大模型 API Key（或兼容 OpenAI 协议的本地模型如 Ollama / LM Studio）。

1. 点击左侧导航栏底部的「设置 → 模型设置」。
2. 选择模型提供商（如 DeepSeek、通义千问、Kimi、GLM、OpenAI、Anthropic 等）。
3. 填入 API Key，点击「验证连接」。验证成功后即可作为主模型使用。
4. 建议同时配置一个备用模型，保障高可用。

详细看 [模型设置](#manual/models)。

## 第二步：导入业务资料

1. 点击左侧导航栏的「知识」。
2. 可以直接在「手动录入」中编写问答对、规章制度或产品参数；
3. 也可以将本地的 Markdown、TXT、PDF 或 ZIP 压缩包直接拖拽至「快速导入」区；
4. 还可以配置自动同步的 GitHub 知识来源。

详细看 [怎么把资料丢进来](#manual/import)。

## 第三步：试答与草稿生成

1. 在「知识 → 导入与试答」页面，输入客户可能提出的咨询问题。
2. 点击「试答」，系统将利用本地向量与关键词检索相关知识，调用大模型生成标准答复。
3. 如果答复不准确，可针对性补充修改知识条目。

验证完毕后，你可以利用咔哒整理客户档案、生成跟进清单，或通过 MCP 服务将知识连接至 Claude、Codex 等其他 AI 智能体中。
